# Operation Blackout

A NumPy and Matplotlib project exploring binary array transformations to investigate a hidden visual pattern.

## Objectives
- Load and inspect a binary NumPy array.
- Reshape a 1D array into a 12 × 12 matrix.
- Experiment with transposition, reversing, flipping and rotation.
- Apply binary pixel inversion.
- Visualize transformations using Matplotlib.

## Technologies
- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The original dataset contains 144 binary values (0 and 1).

## Results
The transformations produce different orientations of a ring-like pixel pattern. The intended textual message has not yet been independently verified.

## Files
- `Operation_Blackout.ipynb` – Complete implementation.
- `operation_blackout_encoded (1).npy` – Original dataset.
- PNG files – Visualization outputs.
